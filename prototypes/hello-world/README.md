# hello-world

The original smoke-test surface: a button, a response line, a status card.

**Not a template. Do not copy this to start a prototype.** It has visual opinions — palette,
type, layout — and starting here produces a variant of it rather than a new bet.

Start from the scaffold instead:

```bash
make new NAME=<kebab-name>
```

Kept only as a minimal check that the serve pipeline works.
